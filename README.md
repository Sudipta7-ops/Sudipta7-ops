## 📌 Projects

### 📮 [Post Office Management API](https://github.com/Sudipta7-ops/post-office-mgmt-api)
**Apr 2026 – Present**

A production-grade REST API digitizing real Indian post office operations — designed from scratch based on my daily experience at India Post.

**Key Features:**
- JWT authentication with custom Employee ID login (not username)
- Role-based permissions — ABPM, BPM, and Admin access levels
- Speed post booking with article number format validation (EE123456789IN)
- Full mail bag workflow — receive, scan, invoice, dispatch
- Search, filter, ordering & pagination on all resources
- Custom JSON exception handling + API versioning (/api/v1/)
- 5+ unit tests | CI/CD via GitHub Actions | Deployed on Render

**Tech:** Python 3.12 · Django 6.0 · DRF · PostgreSQL · JWT · GitHub Actions · Render

**🔗 [Live API](https://post-office-mgmt-api.onrender.com)** | **💻 [GitHub](https://github.com/Sudipta7-ops/post-office-mgmt-api)**
